# 数据收集优先级（基于v5.3方案）

## 优先级1：必需的核心数据

### 1.1 多癌种免疫治疗scRNA-seq数据
**要求**：
- 治疗前/后配对样本
- 包含疗效评估（RECIST/mRECIST/pCR等）
- 多种免疫治疗组合
- 足够的样本量（每癌种≥30例）

**目标癌种**：
1. 肝癌（HCC/ICC） - 高优先级
2. 非小细胞肺癌（NSCLC） - 高优先级  
3. 黑色素瘤 - 高优先级
4. 肾细胞癌（RCC） - 中优先级
5. 头颈鳞癌（HNSCC） - 中优先级
6. 三阴性乳腺癌（TNBC） - 中优先级
7. 结直肠癌（CRC） - 低优先级

### 1.2 扰动数据先验
**已确认**：
- GSE306429（大规模扰动数据集）

**需要补充**：
- 免疫细胞特异性扰动数据
- T细胞耗竭相关扰动数据
- 免疫检查点相关扰动数据

### 1.3 药物表达数据
**来源**：
- LINCS/CMap数据库
- 免疫治疗相关化合物的表达谱

## 优先级2：增强数据

### 2.1 多组学数据
- scRNA-seq + scTCR-seq 组合数据
- scRNA-seq + scBCR-seq 组合数据
- 蛋白质组学数据（CITE-seq/REAP-seq）

### 2.2 空间转录组数据
- 肿瘤微环境空间分布
- 免疫细胞空间定位
- 治疗前后空间变化

### 2.3 长期随访数据
- 生存数据（OS/PFS）
- 治疗响应持久性
- 耐药机制数据

## 优先级3：验证数据

### 3.1 独立验证队列
- 不同中心的相似研究
- 不同平台的验证数据
- 不同人群的验证数据

### 3.2 体外验证数据
- 细胞系实验数据
- 类器官模型数据
- 小鼠模型数据

## 风险评估与缓解策略

### 风险1：新数据不足
**可能性**：中等
**影响**：高
**缓解策略**：
1. 扩展搜索时间范围到2025年全年
2. 考虑使用已收集数据集的扩展分析
3. 与原作者联系获取未公开数据

### 风险2：数据质量不一致
**可能性**：高
**影响**：中
**缓解策略**：
1. 严格的质量控制流程
2. 数据标准化和批次校正
3. 敏感性分析验证结果稳健性

### 风险3：计算资源不足
**可能性**：中
**影响**：中
**缓解策略**：
1. 优化算法效率
2. 使用云计算资源
3. 分阶段实施复杂分析

## 成功标准

### 数据收集成功标准
1. 收集到至少5个癌种的免疫治疗数据
2. 每个癌种至少有1个数据集包含治疗前/后配对样本
3. 总样本量超过1000例患者
4. 包含至少3种不同的免疫治疗组合

### 数据质量成功标准
1. 数据完整性>90%
2. 批次效应可校正
3. 临床信息完整
4. 疗效评估标准统一
