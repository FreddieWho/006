# v6.2 探索性研究执行模式

生效日期：2026-08-27

本项目从现在起按探索性生物信息学研究推进，不要求预注册，也不把“预先规定的分析、阈值、estimand、response unlock 或冻结 gate”作为新分析的硬性前提。研究问题、队列、标签、表征、模型和阈值可以在看到证据后迭代，但每次迭代都要说明理由、与旧方案的差异、得到的改进和新增风险。

历史文件（G0/G1、WP6B、Phase 7/8 gate、response lock 等）保留作溯源，不删除；它们描述的是早期控制层，不再约束新的探索分支。历史状态“WP6B stopped / Phase8 not run”仍应如实记录，但不能单独阻止新的探索性分析。

后续允许读取 response/outcome，但必须在结果中明确说明使用位置，并区分探索、验证和外部支持，避免把同一数据既用于发现又包装成独立验证。保留的底线是数据和样本身份不被破坏、路径和版本可追溯、缺失/混杂/不确定性公开、探索性结论不冒充因果或临床结论。

执行入口：`results/v6_2/scientific_engineering_realignment_v1/exploratory_mode_directive_v1.yaml`。
