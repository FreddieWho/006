## Day 3-4: 因果先验整合与GRN架构搭建

### 工作目标
整合扰动数据作为因果先验,搭建共享+特异双层GRN框架

### Day 3 技术细节

#### 3.1 扰动数据处理 (4h)
- **Perturb-seq 数据整合**:
  - 下载 Replogle 2022 / Dixit 2016 等数据
  - 提取基因对 (TF -> target) 及其扰动效应值
  ```python

  # 筛选 |log2FC| > 0.5, adj.p < 0.05
  causal_edges = extract_causal_pairs(perturb_data)
  ```
- **Xatlas-orion 数据**:
  - 提取 enhancer → gene 调控关系
  - 限定在免疫核心基因集内

#### 3.2 因果先验矩阵构建 (4h)
- **构建先验邻接矩阵**:
  ```python
  # 对免疫核心基因集 (2000+ genes), 构建 2000x2000 矩阵
  prior_adj_matrix = np.zeros((n_genes, n_genes))
  for (tf, target, direction, confidence) in causal_edges:
      prior_adj_matrix[tf_idx, target_idx] = direction * confidence
  # direction: +1 (activation), -1 (repression)
  # confidence: 0-1 (基于实验证据强度)
  ```
- **加入 TF-target 数据库**:
  - 整合 ENCODE ChIP-seq / GTRD
  - 作为无向先验 (confidence=0.3)

### Day 4 技术细节

#### 4.1 双层GRN架构实现 (5h)
- **网络结构设计**:
  ```python
  class DualLayerGRN(nn.Module):
      def __init__(self, n_genes_immune, n_genes_all, n_cancer_types):
          # 共享层: 只在免疫核心基因上学习
          self.shared_grn = CausalGraphLayer(n_genes_immune)
          
          # 特异层: 每个癌种一个残差图
          self.tissue_grns = nn.ModuleList([
              CausalGraphLayer(n_genes_all) 
              for _ in range(n_cancer_types)
          ])
          
          # 因果约束模块
          self.causal_prior = prior_adj_matrix
  ```
- **CausalGraphLayer 设计**:
  ```python
  # 使用 masked adjacency matrix + DAG constraint
  # Zheng 2018 NOTEARS 或改进版 DAGMA
  A = masked_sigmoid(W) * (1 - I)  # 去自环
  ```

#### 4.2 损失函数设计 (3h)
- **总损失函数**:
  ```python
  L_total = (
      sum(w_cancer * L_pred[c] for c in cancer_types)  # 加权重建损失
      + λ_share * L_shared                              # 共享层正则
      + λ_tissue * L_tissue_specific                    # 特异层稀疏性
      + λ_causal * L_grn_prior                          # 因果先验对齐
      + L_reg                                           # DAG约束 + L1正则
  )
  ```
- **各项损失细节**:
  - **L_pred**: 表达预测的 MSE 或 Negative Binomial loss
  - **L_shared**: 鼓励共享图在所有癌种上一致的约束
    ```python
    # 最大化共享图对所有癌种表达的解释方差
    L_shared = -mean([explained_var(shared_grn, data[c]) for c in cancers])
    ```
  - **L_tissue_specific**: L1 稀疏性,限制特异边数量
  - **L_grn_prior**: 学习到的边与先验的一致性
    ```python
    L_grn_prior = ||A_learned ⊙ prior_adj_matrix||_F^2 
                  + λ_anti * ||A_learned ⊙ (1-prior_adj_matrix)||_F^2
    # ⊙ 是元素积, 鼓励与先验一致,惩罚与先验矛盾
    ```
  - **L_reg**: DAG约束 h(A) = tr(e^A) - n = 0 (软约束变为 α*h(A)^2)

      ),
      'DAG Constraint': h_dag < 0.1,
      'One Key Module Identified': len(module_1st_genes) > 0
  }
