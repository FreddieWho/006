# 科研方案 v5.2b

**Multi-cancer immunotherapy-specific causal GRN with structured flow for PD-1+X / X+X combination ranking & target recommendation**

> 版本说明：在 v5.2a 的基础上**充实**了方法学细节并**恢复**早期版本的关键卖点（连续动力学/反事实/零样本评估/训练护栏/结构阈值），同时保持整体相对简练，确保信息完整、可执行、可复现，且不沦为“缝合”。

---

## 1. 科研目标与定位

### 1.1 总体目标（正面任务定义）

在**多癌种免疫治疗**场景下，学习“共享+特异”的**因果GRN**与其**结构化连续流场**，以此对候选 **PD-1+X** 或 **X+X** 组合进行**相对效能排序（ranking）**，并输出可干预**靶点/药物**的**分层推荐**（Tier A/B/C）。算法达标后，进入**体外最小验证 + 目标化体内验证**，形成顶刊（NC/NM/CC）叙事闭环。

### 1.2 卖点（单核 + 三配件）

* **单核（新颖性）**：**SS-CGF：Shared–Specific Causal Graph Field**
  在共享+特异因果图上学习“治疗前→后”的**结构化可微流**，量化“进入应答域”的**可达性/能量/时间**，服务组合排序与干预优先级。
* **三配件（最小必要）**：
  ① **ICSmini**（反事实增量 ΔPr(response)）
  ② **e_X-mini**（两源治疗嵌入：LINCS反向表达 + GRN靶点映射）
  ③ **双护栏**（训练期低权重辅助头：PROGENy通路、TF活性）

---

## 2. 生物学假设（双层 + 可干预）

1. **双层免疫机制**：应答关键过程（抗原呈递、IFN响应、CD8浸润）存在跨癌种**共享**结构，同时保留肝/肺/黑色素瘤等**特异**免疫约束（如肝耐受）。
2. **因果可提升**：扰动先验（perturb-seq/Xatlas）作为**软约束**提升方向可信度，但不替代数据驱动。
3. **可干预路径**：模块中**高中心性+扰动敏感+可药化**基因是组合/靶点优先对象。
4. **阶段门控**：算法与体外达标后再进入体内验证，避免无效实验消耗。

---

## 3. 数据与免疫核心基因集

* **多癌种免疫治疗单细胞**：含治疗前/后（部分配对）、疗效（如RECIST）。
* **先验资源**：LINCS1000、perturb-seq、Xatlas-orion。
* **免疫核心基因集**：ImmPort + MSigDB C7 + ICI相关signature，合并去重得 ~2,000–2,500 基因；

  * 共享GRN仅在该集合上学习；
  * 特异层可在全基因上学，但对已知器官特异基因降权。
* **最小可用多癌种配置（MVC）**：

  * **每癌种≥30例**方纳入**特异层**推断（<30 只参与共享层）；
  * 任一**中心×癌种占比≤40%**，超限则加权并在补充表披露。

---

## 4. 技术路线（七层 + 连续增强）

### Layer 0｜多癌种整合与加权

scVI/Harmony 批次校正；按中心×癌种构造样本权重 (w_{center,cancer}) 并入训练损失，抑制大样本癌种主导。

### Layer 1｜TME与细胞状态

聚类/注释/状态（免疫/肿瘤），记录**前→后**与**应答 vs 非应答**差异，供弱监督与后续排序。

### Layer 2｜共享 + 特异因果GRN（主干）

[
L=\sum_c L_{\text{pred}}^{(c)}
+\lambda_{\text{share}} L_{\text{shared}}
+\lambda_{\text{tissue}} L_{\text{tissue}}
+\lambda_{\text{causal}} L_{\text{prior}}
+L_{\text{reg}}
]

* (L_{\text{shared}})：在免疫核心集合上学共享图；
* (L_{\text{tissue}})：各癌种/器官残差结构（保留生物学合理的器官性约束）；
* (L_{\text{prior}})：perturb-seq/Xatlas 方向软约束（**登记区间**见超参）；
* **贝叶斯优化**同时搜索 (\lambda_{\text{share}},\lambda_{\text{tissue}},\lambda_{\text{causal}})。

### Layer 2.5（增强件，可开关）｜**SS-CGF 结构化流场**

* **Flow-matching 或 神经ODE（择一/并二，视数据）**：在因果图上学习“前→后”的可微流，估计**Flow-gain**（推入应答域的效率）与**可达性**（最小能量/时间）。
* **动态一致性微正则**：FM方向与ODE净位移一致性（低权重），仅作方向证据与排序特征。
* **启用条件**：有前/后（配对优先）且跨中心偏差可控；否则**关闭**，不影响主干。

### Layer 3｜预先计划的机制模块

分辨率=1.0（主），模块大小 15–50；成功标准：**≥50% 模块 FDR<0.05**。稳健性：res=0.5/1.5 + weighted-GSEA（仅支持）。若<30%显著 → 启动差异通路/网络社区富集（降级路径写入预注册）。

### Layer 4｜多层级解释 + 结构一致性

GSEA → SHAP-GSEA → 应答差异；**结构阈值**：Top-1000 因果边对 ENCODE/GTRD/STRING 的支持率**≥30%/≥40%**（补充披露）。
**一号共享模块**：在多癌种显著、与应答强关联，用作主叙事与实验对象来源。

### Layer 5｜瓶颈靶点 + **ICSmini**

综合分数
[
\text{Score}(g)=0.4\cdot \text{Centrality}
+0.3\cdot \text{SHAP}
+0.2\cdot \text{PerturbEffect}
+0.1\cdot \text{Druggability}
]
并报告 **ICSmini**：对候选基因施加 do(↑1 SD) 的**反事实增量** (\Delta P(\text{response}))，用于湿实验与组合优先级量化。

### Layer 6｜**组合排序 & 分层推荐**

* **e_X-mini（两源治疗嵌入）**：
  (\rho_{\text{total}}=0.6\cdot \rho_{\text{LINCS}}+0.4\cdot \rho_{\text{GRN-target}})，**(\rho_{\text{total}}\ge 0.5) 方纳入**；
* **排序特征集（可加权学习）**：
  {模块修复幅度Δscore、**ICSmini**、**Flow-gain**、**ODE-reachability**(若启用)}；
* **零样本（ZSL）度量**：对留出的 X+Y 组合报告 **Top-3 命中率** 与**相对排序一致率**；
* **Tier A/B/C**（准入定义不变）：A=免疫联合相关FDA已批或II/III期且机制契合；B=研究级/LINCS反向支持（标“需体外验证”）；C=暂无药，仅报机制。

---

## 5. 验证与成功标准（含外部锚点与体内目标）

### 5.1 计算与稳健性

* **LOCO（留一癌种）/留一中心**：**平均AUC≥0.73** 且 **95% CI 宽≤0.15**；样本<30 的癌种仅作描述性；
* **消融**：去掉 (\lambda_{\text{share}}) 或 (\lambda_{\text{tissue}}) 或 (\lambda_{\text{causal}}) 性能下降（报告ΔAUC/ΔAUCPR）；
* **多分辨率/降级**：按预注册执行并披露；
* **跨折稳定性**：关键边/模块跨折一致性**≥70%**（补充披露）。

### 5.2 外部“弱锚点”（患者层）

在可得的免疫治疗**bulk/空间队列**计算“一号共享模块score”，评估应答区分（即使中等AUC），作为“跨平台临床相关性”锚点。

### 5.3 体外与体内（阶段门控）

* **体外（投稿包的一部分）**：对“一号共享模块”的Top-1/Top-3候选做最小验证（敲低/抑制→免疫相关readout）。
* **体内（目标化描述，不展开细节）**：算法+体外达标后，验证

  1. 免疫障碍被部分解除；2) 与PD-1/PD-L1 联用疗效增强；3) 共享靶点在代表性癌种模型可复现。

---

## 6. 预注册清单（最小可核查）

* **假设**：H1≥2个共享免疫模块（FDR<0.05）；H2 至少1个癌种特异模块与已知器官免疫约束相符；H3 Top-3 靶点中≥1个 **ICSmini>0** 且体外方向一致。
* **主/稳健/降级顺序**、**成功阈值**（模块≥50%，LOCO AUC与CI）与**结构阈值**（ENCODE/STRING）登记；
* **超参登记区间**：(\lambda_{\text{share}}\in[0,0.4])、(\lambda_{\text{tissue}}\in[0,0.5])、(\lambda_{\text{causal}}\in[0,0.5])，Bayes-opt **n_calls=20**；偏离需披露。
* **MVC/QC守门**：每癌种≥30例、中心×癌种≤40%、单例≥5,000细胞（≥70%样本达标）；负控（暴露/结局/边）与异常剔除规则登记。

## 7. 复现与对比（简述）

* **代码/脚本**随发表开源（训练/评估/可视化/预注册模板）；
* **对比基线**：多样本整合+差异通路、黑箱应答预测、静态GRN；报告 ΔAUC/ΔAUCPR、ZSL-Top-3、一致率与结构阈值；
* **图谱可视化**：共享/特异网络、模块–药物–ICSmini 一图联动（主文：一号共享模块；补充：其余）。

---

## 8. 风险与关闭条件（避免走偏）

* **前/后样本稀缺或跨中心差异大**：关闭 SS-CGF（流/ODE），仅用静态因果GRN+先验；
* **LINCS 覆盖不足**：仅输出 Tier A（免疫联合相关FDA/II–III期）与机制级发现；
* **性能不达标**：转为“机制图谱+工具”型叙事，保留结构阈值与ZSL结果，避免过度承诺。
