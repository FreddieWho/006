# 科研方案 v5.3

**Multi-cancer immunotherapy-specific causal GRN with Structured Flow for PD-1+X / X+X Combination Ranking & Target Recommendation**

> 版本要点：在 v5.2b 基础上，整合“中间层信号（M-signals）三件套+九个辅读数”，保持**单一算法卖点**（SS-CGF：共享-特异因果图上的结构化连续流）与**三配件**（ICSmini、e_X-mini、双护栏），并为**每一模块**给出评估与**保留/可修改**标签（不确定时标注“必须保留”）。

---

## 1. 科研目标与定位 〔必须保留〕

* 在**多癌种免疫治疗**场景下，学习**共享+特异**的**因果GRN**及其**结构化连续流（SS-CGF）**，对候选 **PD-1+X / X+X** 组合进行**相对效能排序**并输出**分层推荐（Tier A/B/C）**。
* 算法达标后进入**体外最小验证**与**体内目标化验证**，形成 NC / NM / CC 级叙事闭环。
* 若预测不够亮眼，以**中间层机制读数**（FG / mICS / MRI 等）转主打“机制修复与可达性”。

**评估**：顶刊对“平台+硬发现”偏好强；该目标兼顾预测与机制，且有降级路径。→ **必须保留**

---

## 2. 生物学假设（双层+可干预） 〔必须保留〕

1. 跨癌种共享免疫核心机制 + 癌种/器官特异免疫约束并存；
2. 扰动类先验（perturb-seq/Xatlas）可作因果软约束但不替代数据驱动；
3. 高中心性+扰动敏感+可药化的基因为优先干预对象；
4. **阶段门控**：算法/体外达标后再推进体内。

**评估**：与任务与验证逻辑深度绑定。→ **必须保留**

---

## 3. 数据与免疫核心基因集 〔必须保留〕

* **数据**：多癌种免疫治疗scRNA-seq（部分前/后配对+RECIST）。
* **先验**：LINCS1000、perturb-seq、Xatlas-orion。
* **免疫核心基因集**：ImmPort + MSigDB C7 + ICI相关signature，~2,000–2,500基因；**共享层仅在该集合上学习**；特异层全基因学习但对器官特异基因降权。
* **最小可用多癌种配置（MVC）**：每癌种≥30例方纳入特异层；任何**中心×癌种**占比≤40%，超限加权并披露。

**评估**：直接影响共享/特异分辨率与偏倚控制。→ **必须保留**

---

## 4. 算法总体结构（单核+三配件） 〔必须保留〕

* **单核（新颖性）**：**SS-CGF**（Shared–Specific Causal Graph Field）
  在共享+特异因果图上学习“前→后”的**可微结构化流**，度量**进入应答域**的可达性/能量/时间，用于组合排序与干预优先级。
* **三配件**：① **ICSmini**（反事实增量 ΔPr(response)）② **e_X-mini**（LINCS反向表达 0.6 + GRN靶点映射 0.4，阈值ρ_total≥0.5）③ **双护栏**（训练期低权重辅助头：PROGENy通路、TF活性）

**评估**：新颖点集中、实现成本受控，不“缝合”。→ **必须保留**

---

## 5. 技术路线（七层 + 连续增强）

### Layer 0｜多癌种整合与加权 〔必须保留〕

* scVI/Harmony；按中心×癌种构造样本权重 (w_{center,cancer}) 入损失，抑制大中心/癌种主导。
  **评估**：决定泛化与偏倚，低风险高收益。→ **必须保留**

### Layer 1｜TME与细胞状态 〔必须保留〕

* 聚类/注释/状态；记录**前→后**与**应答 vs 非应答**差异，供弱监督与排序特征。
  **评估**：后续读数与排序的输入层。→ **必须保留**

### Layer 2｜共享 + 特异因果GRN（主干） 〔必须保留〕

[
L=\sum_c L_{\text{pred}}^{(c)}
+\lambda_{\text{share}} L_{\text{shared}}
+\lambda_{\text{tissue}} L_{\text{tissue}}
+\lambda_{\text{causal}} L_{\text{prior}}
+L_{\text{reg}}
]

* 共享层在免疫核心基因集；特异层保留器官性残差；先验为扰动方向软约束。
* **超参登记区间**：(\lambda_{\text{share}}\in[0,0.4])、(\lambda_{\text{tissue}}\in[0,0.5])、(\lambda_{\text{causal}}\in[0,0.5])；**Bayes-opt n_calls=20**。
  **评估**：核心层；删除将丧失任务本质。→ **必须保留**

### Layer 2.5｜SS-CGF 连续增强（FM/Neural-ODE，条件启用） 〔可修改〕

* **Flow-matching**或**Neural-ODE**在因果图上学习“前→后”的可微流；导出**Flow-gain**与**可达性**（最小能量/时间）；
* **动态一致性**微正则（低权重）约束FM方向与ODE位移一致；
* **启用条件**：有配对或足量前/后且跨中心偏差可控；否则关闭，不影响主干。
  **评估**：显著提升方向性与可达性证据，但资源/数据要求更高；可按数据切换。→ **可修改**

### Layer 3｜预先计划的机制模块 〔必须保留〕

* 分辨率=1.0（主），模块 15–50；成功标准：**≥50% 模块 FDR<0.05**；
* 稳健性：res=0.5/1.5 + weighted-GSEA（不作主结论）；
* 降级：显著模块<30% → 差异通路/网络社区富集（按预注册）。
  **评估**：防“事后挑选”的关键。→ **必须保留**

### Layer 4｜解释 + 结构一致性 〔必须保留〕

* 标准GSEA → SHAP-GSEA → 应答差异；
* **结构阈值**：Top-1000 因果边对 ENCODE/GTRD/STRING 支持率**≥30%/≥40%**（补充披露）；
* 指定**一号共享模块**作为主叙事与实验对象来源。
  **评估**：结构合规与主故事锚点。→ **必须保留**

### **Layer 4.5｜中间层信号（M-signals）**

> 既服务排序，也可独立构成“机制学”结果。全部在外层留出（LOCO/组合留出）上计算，报效应量与95%CI。

**主读数三件套（必须保留）**

* **FG（Flow-gain）**：沿SS-CGF进入应答域的单位路径效率。〔必须保留〕
* **mICS（Module-ICS）**：模块内ICSmini的中心性加权均值。〔必须保留〕
* **MRI（Mechanism Restoration Index）**：施加X或X+Y后“机制修复幅度”= 共享模块分数提升 × FG。〔必须保留〕

**辅读数（九项）**

* **RT（Reachability-Time, ODE）**、**FΔH（Flow-ΔEntropy）**、**VA（Velocity-Alignment）**〔VA可用队列上报〕 → 方向性/动力学证据。〔可修改：VA/RT可按数据与资源开关；FΔH保留〕
* **STR（Shared/Tissue Ratio）**、**ESR（Edge-Support Rate）**、**BNS（Bottleneck Shift）** → 网络/因果结构证据。〔ESR必须保留；STR建议保留；BNS可修改〕
* **E_Ki67（CD8扩增得分）**、**TAM-ΔM2→M1（极化差）**、**LRG（L–R增益）**、**SPP（空间代理）** → TME层证据。〔E_Ki67、LRG必须保留；TAM/SPP可修改〕

**评估**：三主读数决定“失败转机制学”的硬度；辅读数补强可解释性与可视化。→ 三主读数**必须保留**；辅读数按注明开关。

### Layer 5｜瓶颈靶点 + ICSmini 〔必须保留〕

* 评分：0.4·Centrality + 0.3·SHAP + 0.2·PerturbEffect + 0.1·Druggability；
* 报告 **ICSmini**：do(↑1SD) 反事实增量 ΔPr(response)；**跨折一致性≥70%** 方入主文。
  **评估**：湿实验与组合优先级的量化依据。→ **必须保留**

### Layer 6｜组合排序 & 分层推荐 〔必须保留（主体）/可修改（实现细则）〕

* **e_X-mini**：ρ_total≥0.5 方纳入；
* **排序特征集**：{Δ模块分数、**ICSmini**、**FG**、**ODE-reachability**(若启用)} 加权集成；
* **ZSL 零样本**：留出X+Y组合的**Top-3命中率**与**相对排序一致率**；
* **Tier A/B/C**：A=免疫联合相关FDA已批或II/III期且机制契合；B=研究级/LINCS反向支持（标注“需体外验证”）；C=仅机制。
  **评估**：与任务定义强绑定；实现细则（权重学习、阈值微调）可后置。→ **主体必须保留；细则可修改**

---

## 6. 验证与成功标准 〔必须保留〕

* **LOCO/留中心**：平均AUC≥0.73 且 95%CI 宽≤0.15；样本<30 的癌种仅描述性；
* **消融**：去掉 (\lambda_{\text{share}})/(\lambda_{\text{tissue}})/(\lambda_{\text{causal}}) 各自导致ΔAUC↓（报告ΔAUC/ΔAUCPR）；
* **结构阈值**：ESR 满足 ENCODE≥30% / STRING≥40%；
* **ZSL**：Top-3命中率与排序一致率披露；
* **多分辨率/降级**：按预注册执行并披露；
* **跨折稳定性**：关键边/模块一致性≥70%。

**评估**：编辑与审稿人“硬卡口”。→ **必须保留**

---

## 7. 外部锚点与实验（阶段门控） 〔必须保留（目标级）〕

* **外部锚点**：在可得免疫治疗 bulk/空间队列上计算“一号共享模块score”，报告对应答区分（中等AUC亦可）。
* **体外（投稿包必做）**：对“一号共享模块”Top-1/Top-3候选做最小验证（敲低/抑制→免疫相关readout）。
* **体内（目标化描述，不展开细节）**：算法+体外达标后，验证(1)免疫障碍解除趋势；(2) 与PD-1/PD-L1联用疗效增强；(3) 共享靶点在代表性癌种模型可复现。
  **评估**：保证“平台→实体证据”的最小闭环。→ **必须保留（目标级）**

---

## 8. 预注册清单（最小可核查） 〔必须保留〕

* **H1** ≥2个共享免疫模块（FDR<0.05）；**H2** 至少1个癌种特异模块对应器官免疫约束；**H3** Top-3靶点中≥1个 **ICSmini>0** 且体外方向一致；
* **主/稳健/降级顺序**、**成功阈值**（模块≥50%，LOCO AUC 与 CI）、**结构阈值**（ENCODE/STRING）、**MVC/QC守门**登记；
* **超参区间**：见 Layer 2；偏离需披露。
  **评估**：防p-hacking，增加稿件可信度。→ **必须保留**

---

## 9. 复现与对比 〔必须保留（承诺级）/可修改（细节）〕

* **开源**：训练/评估/可视化脚本与`M_signals_*`表；
* **对比基线**：多样本整合+差异通路、黑箱应答预测、静态GRN；报告 ΔAUC/ΔAUCPR、ZSL指标、结构阈值；
* **图谱**：共享/特异网络与模块–药物–ICSmini 联动可视化。
  **评估**：顶刊要求的可复现性；对比细节可后置。→ **承诺必须保留；细节可修改**

---

## 10. 风险与关闭条件 〔必须保留〕

* **前/后样本稀缺或跨中心差异大**：关闭 SS-CGF（FM/ODE），仅用静态因果GRN+先验；
* **LINCS 覆盖不足**：仅输出 Tier A 与机制级；
* **性能不达标**：转“机制修复”主线（**mICS+MRI+ESR**），组合排序降为探索性。
  **评估**：可控降级，避免走偏。→ **必须保留**
