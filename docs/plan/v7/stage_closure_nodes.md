## Stage 0｜范围、资产与发布入口

- **问题**：现行 v7 与历史资产、代码、计划及状态能否清晰区分？
- **已有证据**：v7 plan/roadmap、目录规范、继承清单与迁移报告已存在。
- **最小补齐**：将当前 dirty worktree 的具体代码/配置版本纳入后续运行 provenance；核对活跃入口与继承资产映射，补齐变更来源；Git 发布状态单独记录，不从本地结果推断远端已发布。
- **结果判定**：当前输入、原版本与修订范围可定位，原目标没有被历史结果替代。问题仅涉及文档时不重跑科学计算。
- **偏移评估**：接受逻辑归档、只读引用与复用；不要求移动大型数据。取消历史硬门槛不等于取消独立性和证据标准。
- **节点文档**：`results/v7/inheritance/` 五件套；引用 `docs/v7/REPOSITORY_MIGRATION.md` 和 `asset_manifest.tsv`。
- **下游资格**：Stage 1–10 能定位同一套科学范围与运行代码；剩余版本冲突逐项明示。

## Stage 1｜身份、数据角色和可识别性

- **问题**：哪些资产支持哪个 claim，真正独立样本数是多少？
- **已有证据**：跨项目 logical/physical registry、患者层级、治疗/response、重复来源及 claim 角色表。
- **最小补齐**：只针对 Stage 4–9 实际候选来源核对身份链、counts/坐标/模态、时间点、治疗/endpoint、重复关系和选择暴露；将“库存存在”“本地可运行”“临床/纵向可识别”分列。
- **结果判定**：每个候选来源明确 discovery、validation、support 或 reject；未知身份不增加独立患者。缺数据的资格审计可结束，但其对应科学问题仍不可识别。
- **偏移评估**：接受按具体 claim 重新分配角色；用过的验证数据不能在同一 claim 下恢复独立身份。
- **节点文档**：`results/v7/registry/` 五件套；复用 `REGISTRY_REPORT.md`、现有 crosswalk 和 role assignment。
- **下游资格**：分别交付空间发现、结构验证、临床、配对、扰动、X-class 的合格资产清单与缺口；代理资格不额外要求 response。

## Stage 2｜测量与共同词汇

- **问题**：哪些功能对象在什么模态和载体中可可靠测量？
- **已有证据**：44 个对象、39 个特征；7 个 scRNA measurable、32 个 uncertainty；bulk 两位精确配对仅描述性，扰动重复性不等于方向验证。
- **最小补齐**：把每个主分析特征连接到覆盖率、carrier、null、跨研究稳定性和 score 语义；核对 Stage 7 的 pre/post 使用可比尺度且未回归掉治疗信号；对具体失败链条做定向修复。
- **结果判定**：逐特征×模态判定可测/有限/拒绝；不存在“scRNA D2 自动推广到 bulk/spatial”。共同词汇接口可完成，无法校准的模态桥单列未完成。
- **偏移评估**：接受父轴多组件、平台子空间和 abstention；保留39特征覆盖审计，不能通过静默删掉失败特征改善完成度。
- **节点文档**：`results/v7/ontology/` 五件套；引用 `ONTOLOGY_AND_MEASUREMENT_REPORT.md`、reliability 与 bridge contract。
- **下游资格**：给出主要、敏感性、仅注释三类输入，以及每类允许的统计解释。

## Stage 3｜空间基础设施

- **问题**：空间输入、坐标、图和患者层级能否可靠回放？
- **已有证据**：8 个逻辑 pilot、11 个捕获、7 个患者身份包；D3 带限制通过，跨平台共同完整可测特征只有1个。
- **最小补齐**：将 Stage 4 扩展资产连接到同一 adapter/身份/分割/坐标合同；新增或改变的路径才做技术回放；明确 kNN 邻接不等于真实细胞接触。
- **结果判定**：合格输入可重放，计数与坐标语义闭合，不跨 section/patient 连边；不在此判定屏障、疗效或潜在场成立。
- **偏移评估**：接受按平台独立构图和统计层对齐；不强迫 panel 缺失补零或完全同分布。
- **节点文档**：`results/v7/spatial_foundation/` 五件套；引用现有 D3_GATE 和 run manifest。
- **下游资格**：给 Stage 4 精确到 unit 的可用输入、特征覆盖和不允许的结构解释。

## Stage 4｜空间发现、增量与结构验证

- **问题**：是否存在超越丰度的可复现结构；是否发现稳定的开放潜在场？
- **已有证据**：43 位患者、71 个捕获；5 个预定义 proxy 原语；Moran、NMF 与描述性队列移除检查。当前增量定义和留出输出不足以满足原问题。
- **最小补齐**：按总体方案4.1修复增量、患者平衡、held-out、NMF误差/收敛/稳定性、置换精度；对全部5原语输出结果；保留合格的独立 TLS/边界等结构验证，使用前记录其claim暴露。
- **结果判定**：分别判定原语重复性、topology 增量、已知结构锚定、开放潜在场、跨队列/平台迁移。有效检验后无增量或 K_eff=0 可形成否定结论；未收敛且未完成可行替代检验不算闭合。
- **偏移评估**：透明原语可保留为正式基线；简单因子可替代复杂模型，但需要同一问题的验证。若仅完成原语分支，开放场分支仍单列未完成。
- **节点文档**：`results/v7/spatial_discovery/` 新运行五件套；核心表含 baseline comparison、held-out result、convergence/stability 和 claim-level decisions，原结果保留。
- **下游资格**：向 Stage 6 提供版本化结构及 carrier、尺度、方向、验证范围；未获增量支持者不能作为已成立屏障进入 repair。

### Stage 4B｜结构代理子节点

- **最小补齐**：审计同患者/可匹配的空间目标与非空间可测输入；拟合与验证均 response-blind；患者外层留出，独立数据评价误差、相对 abundance 基线的增量、覆盖与 abstention。
- **结果判定**：逐 architecture×目标模态验证；无合格配对或迁移失败则不准进入非空间疗效/repair 的 topology claim。无 response 不独自构成代理阻塞。
- **偏移评估**：代理先于临床锚定验证符合原科学目标；局部模态成功只能授予局部资格。
- **节点文档**：纳入 Stage 4 五件套独立小节和 `architecture_surrogate_validation.tsv`；保留独立任务状态。

## Stage 5｜临床锚定

- **问题**：哪些分子/细胞/合格空间对象在可比环境内与response相关，并有基线之外的信息？
- **已有证据**：125 位患者、5 队列；主分子模型4/5队列 AUROC低于0.5，TASK01联合模型与composition-only表现接近；尚无稳定外部锚定。
- **最小补齐**：核验环境与基线标签；固定共同患者折、训练内预处理和基线；比较配对增量/校准；解释低性能；完成对应 claim 的整队列/独立验证与负对照。若跨环境不可比，不强行合并效应。
- **结果判定**：分开记录分子关联、组成关联、模型增量和外部迁移；结果不佳可闭合具体模型检验，不能顺带否定全部机制。无空间输入时空间锚定仍未完成。
- **偏移评估**：接受composition为主、分子仅辅助，或结果限定某环境；反向预测、标签修订和新特征必须有独立理由及新的选择暴露记录。
- **节点文档**：`results/v7/clinical_anchor/` 新运行五件套；以固定fold/OOF表、baseline增量、特征效应和验证结果为证据。
- **下游资格**：给 Stage 7 明确来源与验证角色的 responder-compatible 方向；同一患者不能同时用于方向选择和独立验证。

## Stage 6｜共享结构、context 与 HCC

- **问题**：哪些结构功能共享，哪些差异是器官实现而非平台/组成/取材造成？
- **已有证据**：5个候选、15个dataset/platform实现；HCC来自GSE238264的7位post-only患者，当前为描述性结果。
- **最小补齐**：锁定 Stage 4 候选；患者层级比较及leave-cohort/platform评估；独立HCC复现；分析可获得的组成、区域、纯度、ambient、治疗和平台影响，显式记录不可分离设计。
- **结果判定**：shared / context-modulated / context-specific / conflicting / unresolved，逐对象给出证据；无独立HCC数据则HCC复现任务未完成，不能用非HCC替代。
- **偏移评估**：接受从泛癌共享改为有限context-specific结论，前提是检验充分且范围变化显式；post-only空间只保留结构支持角色。
- **节点文档**：`results/v7/context/` 新运行五件套；附独立性、设计可识别性、混杂敏感性和逐候选结论。
- **下游资格**：给 Stage 7/8 的是经判定的功能、carrier、context和不确定性，不把并列临床注释变成空间疗效证据。

## Stage 7｜配对重排与 repair 判断

- **问题**：组合治疗的患者内变化是否沿削弱可信障碍的方向移动？
- **已有证据**：TASK01/TASK02共47位配对患者、3,432条分子位移；156行兼容性表方向均未指定，空间分支不可识别。
- **最小补齐**：从独立机制/Stage8或训练数据确定候选方向；检验留出患者的分子和cell-state位移、composition调整、患者区间、完整向量配对/时间/response对照；补独立组合患者验证及合格负例。
- **结果判定**：每个候选分别给方向相容/不相容/不确定；分子位移、代理空间重排、直接空间重排分列。无空间桥时后两者不得提升，原空间repair任务保持未完成。
- **偏移评估**：接受非因果兼容性、线性轨迹或方向统计替代OT；若仅做分子分支，需要保留原空间目标未完成，不能将其改写为整阶段repair成立。
- **节点文档**：`results/v7/repair/` 新运行五件套；新增方向来源、选择/验证拆分、composition敏感性与独立组合结果，保留现有描述性表。
- **下游资格**：交付 Stage 8/9 可检验的具体 X-class×carrier×方向假说；不以单药/组合队列差异推断X因果增量。

## Stage 8｜扰动、靶点与外部患者

- **问题**：真实扰动能否支持方向，靶点是否在相关载体可达，独立患者证据是否一致？
- **已有证据**：接口及候选来源存在；v7方向和外部验证核心计算为NOT_RUN。
- **最小补齐**：对版本化的活动候选集合，审计真实condition/dose/time/carrier与测量语义；计算扰动方向、重复与context-transfer；target/carrier表达；独立患者方向及真实失败/不匹配负例；覆盖不足逐项abstain。
- **结果判定**：方向支持、可达性和外部关联分别判断；单有重复性或target表达不足以判机制成立；冲突不能被一个总分抵消。
- **偏移评估**：可提前运行以帮助Stage7定义机制方向，但被使用的数据归入开发证据；外部验证需另有未参与选择的数据。
- **节点文档**：`results/v7/perturbation/` 与 `results/v7/external_validation/` 各保留来源/运行清单，由一个Stage8主报告连接两个证据分支。
- **下游资格**：给Stage9真实X-class、正负例、context和证据等级；不足的类别不能通过药物别名重复计数。

## Stage 9｜跨 X-class 外推

- **问题**：机制结构能否泛化到未见X-class，并在证据不足时拒答？
- **已有证据**：尚无v7 class-held-out结果，资格需依Stage7–8核定。
- **最小补齐**：先确认至少三类机制不同X-class、可信正/负例与独立组合数据；满足后做class-held-out，与pathway overlap、prototype及additive比较，校准abstention，审计类名/药名/标签泄漏。
- **结果判定**：泛化增量与拒答校准分别判定；不超过简单基线可以形成有效否定结果。资格不足时审计记录完成、科学节点OPEN/NOT_IDENTIFIABLE。
- **偏移评估**：可将单一antiangiogenic类定位为案例研究，显式列为范围变更；不能以leave-one-drug替代leave-one-mechanism-class后继续声称跨类外推。
- **节点文档**：`results/v7/repair/` 中Stage9独立子目录，含五件套和X-class资格表，避免覆盖Stage7节点文件。
- **下游资格**：只有合格外推才进入论文Branch D；否则保留限制与未来解除条件。

## Stage 10｜独立审查与结论交付

- **问题**：第三方能否从原始来源到最终claim独立追踪、复核并识别限制？
- **已有证据**：阶段产物存在；最终Evidence Card、独立复核和论文闭合为NOT_RUN。
- **最小补齐**：形成逐claim证据矩阵、负结果/冲突/未执行表；检查选择后验证、患者独立性和因果措辞；交付图表来源、代码、配置、环境、hash、数据访问限制与最小复核命令。
- **结果判定**：第三方可完成关键结果复核并给出已署名日期的review；无法访问的数据或未复算项目明示NOT_TESTABLE/NOT_RUN。作者自查不能替代独立审查。
- **偏移评估**：允许按证据选择A/B/C/D中的可交付分支；其他原目标保留未完成，最终报告不能写“v7全目标完成”。
- **节点文档**：`results/v7/evidence_cards/`、`FINAL_SCIENTIFIC_REPORT.md`、独立review记录和发布变更记录；新增外部数据同步全局索引。
- **闭合条件**：交付范围内每个claim有证据/判定/偏移/边界；上游阻塞在主结论可见。科学证据不足时可以交付可审查阶段报告，但不冒充达到原定发表标准。

## 第三方审查记录模板

每节点在 DECISION_LOG 追加，不另造重复总结：

| 项目 | 内容 |
|---|---|
| scope_version / run_id | 待执行时填写 |
| reviewer / date / independence | 待第三方实际审查时填写 |
| inputs and outputs inspected | 精确路径、hash、表/行标识 |
| computation reproduced | 命令、环境、结果、容差依据；未运行项明确标记 |
| original requirements unresolved | 原要求、状态、原因、结论影响 |
| deviations reviewed | 每项接受/拒绝/证据待补及理由 |
| claim decisions | 支持/不支持/不确定/不可识别及证据定位 |
| stage closure / downstream permission | 当前范围OPEN/CLOSED、允许下游输入与claim |
| remaining actions | 行动、完成条件、责任人；不能以签署掩盖缺失计算 |
