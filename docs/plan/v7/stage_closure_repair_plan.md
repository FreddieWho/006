## 1. 目的与当前判断

保留现有数据、测量和探索成果，补齐每阶段最小但足以回答问题的计算、结果判定和第三方审查材料。以科学问题是否得到有效检验决定闭合，不按脚本退出、文件数量或阶段编号判定。

本次只交付方案和节点计划；不更改现有结果、科学状态或历史运行。执行时使用新运行目录，逐阶段完成后再更新当前入口。

当前工作基线：

- Stage 0–3：优先复用，补接口、结论边界和文档映射；不默认重跑全量数据。
- Stage 4：完成了首轮 proxy 邻接、Moran 和探索性 NMF，尚缺原方案的 topology 增量、真实留出和结构验证。
- Stage 5：临床基线已计算，缺乏稳定分子增量；不能把运行完成等同临床锚定成立。
- Stage 6：完成 context 描述，独立 HCC 复现和混杂分解尚未闭合。
- Stage 7：完成分子位移，repair 方向、细胞状态/组成调整、独立组合验证和空间分支仍有缺口。
- Stage 8–10：核心计算或最终审查尚未运行。

## 2. 四个维度分别记录

| 维度 | 记录内容 | 禁止的替代 |
|---|---|---|
| 执行 | 每项必需计算的 NOT_RUN / RUNNING / COMPLETE / BLOCKED / NOT_TESTABLE | 有输出文件不等于计算完整 |
| 科学结果 | SUPPORTED / NOT_SUPPORTED / INCONCLUSIVE / NOT_IDENTIFIABLE | 未运行不等于没有效果 |
| 阶段闭合 | OPEN / CLOSED | 某个子分支完成不等于整个阶段完成 |
| 下游资格 | 允许的输入、claim 和阻塞项 | 上游有候选不等于下游可作机制结论 |

结果判定规则：

- **SUPPORTED**：完成所需对照、独立单位分析和验证，达到该 claim 的效应、稳定性和证据要求。
- **NOT_SUPPORTED**：有效检验未支持预先写明的主张。明确否定的是哪个模型、效应范围或迁移命题；声称“无有意义效应”还需等效界值和足够精度。
- **INCONCLUSIVE**：必需分析已执行，但区间、异质性、检验能力或相互冲突使结果无法定向。不能把小样本不显著写成生物学不存在。
- **NOT_IDENTIFIABLE**：当前数据设计不能识别目标，如无纵向空间且无合格代理。身份/资格审计可完成，原科学计算和依赖分支保持未完成。

只有当前版本范围内的必需任务均执行、输出可追溯、结果与偏移已判定，阶段才可 CLOSED；允许以可靠的否定或不确定结果闭合。

核心计算缺失时保持 OPEN。若正式调整范围，分别记录“原范围未完成”和“修订范围是否闭合”，不可改写历史。资源不足、已知数据缺口或报告中的免责声明都不能自动豁免核心任务。

## 3. 接纳正向偏移的规则

每项偏移记录原要求、替代方案、触发原因、预期收益、实际比较证据、损失的可识别范围、选择数据暴露、决策人/日期和状态。

| 偏移 | 可接受条件 | 不能据此声称 |
|---|---|---|
| 用透明统计/简单因子替代 GNN、MNSF 或 transport | 能检验同一科学命题；合格留出比较显示足够效果或复杂模型无稳定增量 | 未运行复杂模型就是复杂模型失败 |
| 按平台、覆盖率和可测子空间分层 | 保留全资产覆盖审计、缺失与 abstention；分别验证允许的迁移范围 | 部分模态成功等于全模态等价 |
| 将预定义原语与开放潜在场分开 | 分别命名、验证和给出结果；开放发现的缺口仍显式存在 | 5 对 marker proxy 是发现了 5 个新屏障 |
| 将 Stage 8 靶点/扰动审计提前 | 作为候选方向先验或独立证据，明确其数据角色；不绕过空间与临床证据 | 靶点可达等于空间 repair 成立 |
| 保留有限但可信的阴性/情境特异结论 | 完成对应检验与失败边界，报告范围与精度 | 单癌种结果等于泛癌共性 |
| 缩小主论文分支或候选集合 | 明确版本化范围、取舍依据和未完成原目标；不得按验证结果挑剩余正例 | 当前分支交付等于完整 v7 全部完成 |

必要或显著有益的技术替代可按上述规则直接推进并记录，不为每个常规实现选择设置额外确认。改变核心科学目标或取消核心证据要求必须成为显式范围决策，不能藏在参数或脚本默认值中。

判定使用 `PROPOSED / ACCEPTED / REJECTED / PENDING_EVIDENCE`。尚未比较的收益只写预期，不能预先归为“已证明的正向偏移”。对同一 claim，参与改方案的数据继续属于开发数据。

## 4. 最小技术修复范围

### 4.1 Stage 4：恢复空间主线的可检验性

1. 将现有 Moran 差值明确归为 proxy-adjustment diagnostic。另建真正的 topology 增量分析：在相同患者留出和相同评估目标下比较 abundance、composition、QC/platform、region、smoothing 与 topology。
2. 独立目标优先使用合格的结构 GT 或未参与选择的结构验证数据；不能用定义候选的同一 marker 构造“真值”。缺少必要真实组成/区域变量时，限制对应结论并保留未完成项。
3. 在患者内汇总或采用嵌套模型；相同患者全部 section/timepoint 同折。真正输出留出队列结果，不只输出训练侧中位数。
4. 保留全部 5 个原语的验证结果和失败记录。共享判断同时要求方向/功能解释、覆盖和独立复现；“可估计”不作为共享证据。
5. 修复 NMF 的 K=0 与 K>0 误差尺度，记录收敛和有效初始化变化；执行有界的 held-out 与子空间稳定性比较。NMF 无增量可作为结果，不强制升级复杂模型。
6. 空间置换保持 section 内结构约束，外层推断尊重患者；按检验数和精度需求设置次数、上限和多重检验族。19 次仅保留为历史探索；新增计算不得按是否显著随意追加。
7. 代理资格审计区分空间—转录配对与 response。结构代理训练/验证不要求 response；临床关联才需要。代理输入必须能在目标非空间模态实际获取，并在未参与选择的患者/数据中验证迁移，不能以空间同源汇总循环证明。

### 4.2 Stage 5：解释临床基线失败并做公平比较

1. 核对 treatment×endpoint×cancer、基线时间点和标签映射，不能未经审计把 dataset 等同单一环境。
2. 固定共同患者折；插补、标准化及任何数据驱动选择在训练折内完成。患病率基线也由训练折估计。
3. 并列 QC、composition、7 个主要分子特征和联合模型；39 特征保留为敏感性，不用现有 response 挑选后宣称独立验证。
4. 报告相对基线的配对增量、校准及患者级不确定性；固定 OOF 预测的 bootstrap 只代表条件性不确定性。若需声称训练稳定性，增加有界重复分折/重拟合。
5. 先解释低于随机水平的结果和组成主导，再决定外部验证对象；采用未触碰队列或明确的整队列留出。结果差不自动归咎标签错误，也不事后翻转预测方向。

### 4.3 Stage 6–8：把描述推进为受限但完整的证据链

1. Stage 6：独立 HCC 来源复现；控制可识别的组成、区域、平台、取材和治疗混杂。设计完全混杂时保留不可识别，不能靠加入共线协变量“修复”。
2. Stage 7：从独立机制/扰动证据或训练患者确定候选 repair 方向；再评价留出或独立患者的位移。已有 response 分层结果保持探索性角色。
3. Stage 7：补真实 cell-state fraction 位移、composition-inclusive/adjusted 并列、患者不确定性和负对照。配对置换以完整患者特征向量为单位，按被检验的 null 保持环境、时间点及需要保留的分层；不逐特征独立打散协方差。
4. Stage 8：在已登记的活动候选集合上完成真实扰动方向、target/carrier 和外部患者证据及负例；完整保留冲突和缺覆盖。重复性、表达可达与药物作用分别判定。
5. 空间 repair 仍需纵向空间或有效代理。单药和组合队列不可交换时只比较非因果兼容性；post-only 空间与非配对临床数据不拼成纵向结论。

## 6. 执行顺序和停止条件

1. **节点建账**：将现有执行状态与科学闭合分开；接入输入、claim、暴露与偏移记录，保留历史状态。
2. **Stage 0–3 轻量补齐**：利用现有审计补文档与接口，只对具体证据缺口重新计算。
3. **Stage 4 核心修复 + Stage 5 临床修复**：二者可独立推进；Stage 4B 做真实资格审计。没有必要先扩大模型复杂度或数据规模。
4. **Stage 6 验证 + Stage 8 方向/可达性先导**：为 Stage 7 提供受限但可审查的候选与方向；先导暴露的数据不能再充当独立验证。
5. **Stage 7 判断 + Stage 8 外部闭合**：完成配对、负例、独立方向检验及空间资格边界。
6. **Stage 9 资格决定**：至少三种机制不同 X-class、可信正负例和独立组合数据齐备才开展 class-held-out；不足则审计记录完成，科学节点保持 OPEN/NOT_IDENTIFIABLE。
7. **Stage 10 审查与发布**：先闭合证据充分的论文分支，同时披露未完成原目标；不能以最终文档齐全掩盖上游科学缺口。

每节点提交一次与风险相称的验证包。第三方优先复算小型判定表或一个关键留出比较，不默认重跑全体大矩阵。已有检查只有输入、代码变化或发现具体疑点才重复。

对行为性代码修复执行针对性回归和必要科学计算；纯文档/接口索引调整只检查路径与字段。独立复核签署需由未承担该项实现与结果选择的人完成，不能由作者自称通过第三方审查。
